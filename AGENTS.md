This is a repo for my resume/CV.

It's written in latex. No need to try and build after making changes. VSCode
updates it automatically.

Any changes you make should sound like they were made by a human, not by an AI.
However, assume that this resume will be read by another AI as a screening so
try to make it so that any changes you make will be picked up by the other AI
and get passed the initial screening process. But make sure if a human reads it,
it sounds like a human wrote it.
